# SCT_DS_4

# SkillCraft Internship Task 4

## Objective
Analyze traffic accident data to identify patterns related to road conditions, weather, and time of day. Visualize accident hotspots and contributing factors.

## Dataset
US Accidents Dataset (March 2023)

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## Analysis Performed
1. Data loading and inspection
2. Missing value analysis
3. Weather condition analysis
4. Accident severity distribution
5. Traffic signal impact analysis
6. Day vs Night accident analysis
7. Accident hotspot visualization

## Results
- Identified common weather conditions during accidents.
- Analyzed accident severity patterns.
- Compared accidents during day and night.
- Visualized accident hotspot locations using latitude and longitude data.

## Conclusion
Traffic accidents are influenced by environmental and road-related factors. Data visualization helps identify patterns and supports road safety decision-making.
